## Recommended Roadmap (2- New)

The current, recommended learning path:

1. **CS50x** (`Education/Career Paths/Web Development/2- New/1- CS50x`)
   - Weeks 0–10 lectures, shorts, and sections covering CS fundamentals, C, Python, SQL, HTML/CSS/JS, and Flask.
2. **The Odin Project** (`Education/Career Paths/Web Development/2- New/2- The Odin Project`)
   - `1- Foundations` — Core web fundamentals (HTML, CSS, Flexbox, JavaScript basics, Git)
   - `2- FullStack JavaScript Path` — Intermediate/Advanced JS, OOP, SOLID, Async JS, Testing, DSA, Git
   - `3- NextJS Bootcamp` — React and Next.js roadmap & bootcamp notes
