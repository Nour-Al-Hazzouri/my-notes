A **Binary Tree** is a non-linear data structure where each "node" contains a piece of data and can point to a maximum of two other nodes, known as the left and right children. Unlike linear structures (like arrays) that have a single path from start to finish, a tree allows for multiple directions at every node. A **Binary Search Tree (BST)** is a specific type of binary tree where data is organized logically: for any given node, values smaller than it are stored in its left subtree, and values larger are stored in its right subtree.

### 1. The Structure of a Node

In a binary tree, the "Node" is the fundamental building block. It must keep track of its own data and its connections to children.

**Code Example: A Binary Tree Node**

```js
class Node {
  constructor(data) {
    this.data = data;
    this.left = null;
    this.right = null;
  }
}
```

**Line-by-Line Breakdown:**

- `class Node { ... }`: A blueprint used to create individual units of the tree.
- `constructor(data) { ... }`: The setup function that runs when we create a new node.
- `this.data = data;`: This line stores the actual information (like a number or character) inside the node.
- `this.left = null;`: A pointer to the left child, initialized to `null` because a new node starts with no children.
- `this.right = null;`: A pointer to the right child, also initialized to `null`.

---

### 2. The Role of Queues in Trees

A **Queue** is a linear structure following the **First-In, First-Out (FIFO)** principle. In tree structures, queues are essential for **Breadth-First Traversal**. Because a tree isn't linear, once you move to a child node, you "lose" the reference to its sibling unless you store it somewhere. A queue acts as a "waiting room" for **discovered nodes**—nodes whose addresses we know but haven't visited yet.

---

### 3. Tree Traversal Strategies

Traversal is the process of visiting every node in the tree exactly once.

#### Strategy A: Breadth-First (Level Order)

This strategy visits all nodes at the current depth (level) before moving to the next deeper level. It uses a queue to track nodes to visit next.

**Code Example: Level Order Traversal**

```js
levelOrder(root) {
  if (root === null) return;
  const queue = [root];

  while (queue.length > 0) {
    let current = queue.shift();
    console.log(current.data);

    if (current.left !== null) queue.push(current.left);
    if (current.right !== null) queue.push(current.right);
  }
}
```

**Line-by-Line Breakdown:**

- `if (root === null) return;`: A "corner case" check; if the tree is empty, we stop immediately.
- `const queue = [root];`: We initialize a queue with the root node. In JS, arrays are often used as queues by convention.
- `while (queue.length > 0) { ... }`: We continue the process as long as there are "discovered" nodes waiting in the queue.
- `let current = queue.shift();`: We remove the node at the **front** of the queue. `shift()` is the native JS method for "dequeueing".
- `console.log(current.data);`: We "visit" the node by processing its data.
- `if (current.left !== null) queue.push(current.left);`: If a left child exists, we add it to the **back** of the queue.
- `if (current.right !== null) queue.push(current.right);`: If a right child exists, we add it to the back of the queue.

#### Strategy B: Depth-First (DFS)

DFS finishes an entire subtree (going as deep as possible) before moving to the next child. These are best implemented using **recursion**.

**Code Examples: The Three DFS Permutations**

```js
// 1. Preorder (Data, Left, Right)
preOrder(node) {
  if (node === null) return;
  console.log(node.data);   // Visit Root
  this.preOrder(node.left);  // Visit Left Subtree
  this.preOrder(node.right); // Visit Right Subtree
}

// 2. Inorder (Left, Data, Right)
inOrder(node) {
  if (node === null) return;
  this.inOrder(node.left);   // Visit Left Subtree
  console.log(node.data);    // Visit Root
  this.inOrder(node.right);  // Visit Right Subtree
}

// 3. Postorder (Left, Right, Data)
postOrder(node) {
  if (node === null) return;
  this.postOrder(node.left);  // Visit Left Subtree
  this.postOrder(node.right); // Visit Right Subtree
  console.log(node.data);     // Visit Root
}
```

**Recursive Breakdown (Common Logic):**

- `if (node === null) return;`: This is the **base case**. It prevents infinite recursion by stopping when we hit a leaf's child.
- **The Order of Lines:** The only difference is when you log the data.
    - **Preorder:** Useful for cloning a tree; you process the parent before the children.
    - **Inorder:** In a BST, this prints values in **sorted order**.
    - **Postorder:** Useful for deleting a tree; you process children before the parent.

---

### Additional Context & Summary

- **Space Complexity:** Level Order (Breadth-First) space depends on the **width** of the tree (max nodes in the queue), while DFS space depends on the **height** of the tree (max calls on the stack).
- **Time Complexity:** All traversals are **O(n)** because every node must be visited exactly once.

### Revision Summary

**Binary Tree Node** - The basic unit containing data and two child pointers.

```js
class Node {
  constructor(data) {
    this.data = data;
    this.left = null;
    this.right = null;
  }
}
```

- `data`: The stored value.
- `left/right`: Pointers to other Node instances or `null`.

**Level Order Traversal** - Visiting nodes level-by-level using a FIFO queue.

```js
levelOrder(root) {
  if (!root) return;
  const queue = [root];
  while (queue.length) {
    let node = queue.shift();
    console.log(node.data);
    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }
}
```

- Uses `shift()` to dequeue from the front and `push()` to enqueue at the back.

**Inorder Traversal** - A recursive depth-first strategy that visits the left, then the root, then the right.

```js
inOrder(node) {
  if (!node) return;
  this.inOrder(node.left);
  console.log(node.data);
  this.inOrder(node.right);
}
```

- Yields sorted data when used on a Binary Search Tree (BST).

**Full Picture Example: A Binary Search Tree Class**

```js
class BST {
  constructor() {
    this.root = null;
  }

  // Recursive DFS (Inorder)
  printSorted(node = this.root) {
    if (!node) return;
    this.printSorted(node.left);
    console.log(node.data);
    this.printSorted(node.right);
  }

  // Breadth-First (Level Order)
  printLevels() {
    if (!this.root) return;
    const queue = [this.root];
    while (queue.length) {
      let current = queue.shift();
      console.log(current.data);
      if (current.left) queue.push(current.left);
      if (current.right) queue.push(current.right);
    }
  }
}
```
